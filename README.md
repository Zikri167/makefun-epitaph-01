A program that writes one original one-line epitaph of famous last words to /output/entry.txt for make.fun's "Famous Last Words: The Funniest Epitaph" bounty — a single line, under 150 characters, judged pairwise by a graveyard judge on whether it really is a one-line epitaph, how real the laugh is, how clean the twist lands, how much it reads like carved stone, and how quotable it stays.

## Run it

```sh
node main.ts
```
